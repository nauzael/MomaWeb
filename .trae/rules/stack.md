# Reglas para Ti

## Código
- camelCase para funciones/variables
- PascalCase para componentes/tipos
- Tipado explícito en TypeScript (no `any`)
- Imports con `@/` (ej: `@/components/Button`)

## Seguridad
- Toda API debe validar auth
- Sanitizar inputs del usuario
- Credenciales solo en `.env`

## Performance
- Paginación máx 100 registros
- useMemo/useCallback cuando corresponda

## Prohibido
- `any` sin justificación
- `console.log` en producción
- `catch` vacío
